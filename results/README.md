# Saved experiment results

Each numbered experiment contains the original descriptive run directories, grouped without changing their scientific labels or numerical results. Case-level evidence and LLM response/metadata records are retained where available. Absolute workstation paths have been converted to repository paths; hashes before and after relocation appear in `publication_manifest.csv`.

- `experiment_1`: the two Anytown calibration runs supplying the main calibration figure.
- `experiment_2`: five-model comparisons, classical baselines, individual model runs, and the cross-network summary.
- `experiment_3`: generalized verifier v4, family evidence, model rankings, ordering comparisons, and cross-network summaries.
- `experiment_4`: operational-context runs, focused verification, and pooled summaries.
- `sensitivity`: the fixed-evidence 1,296-setting-per-network decision-policy sensitivity analysis.
- `source_inputs`: earlier benchmark input/evidence snapshots required to interpret and rerun the selected pipeline. These are not additional headline evaluation cases.
