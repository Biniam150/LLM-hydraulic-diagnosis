# Anytown input

`anytown.inp` is copied from the study's `anytown network.inp`. The exact file hash and original project-relative location are in `results/publication_manifest.csv`.

The study profile uses WNTR with pressure-dependent demand. This is the specific study variant; it should not be assumed identical to every distributed Anytown model.
